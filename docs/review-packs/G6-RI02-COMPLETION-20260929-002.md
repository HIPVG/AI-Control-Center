## Rejection addressed

The first pack was rejected because `JsonRunStore.versions()` accepted any valid
RunRecord JSON found in the target run's history directory. A different run could
therefore become the supposed initial version used for admission.

Revision 002 changes only that persisted-version read boundary:

- `versions(run_id)` first requires the target current RunRecord when history exists.
- Every historical version must have the requested run ID.
- Every historical version's complete immutable `RunIntent` must equal the current
  RunRecord's intent before any version is returned.
- A semantic mismatch raises at the store boundary. The read-time composition maps
  that failure to `RUN_VERSION_HISTORY_UNREADABLE` and returns no selected/current
  run, criteria, telemetry or admission.
