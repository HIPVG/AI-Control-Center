# 手動外部ゲート・レビューパック

このディレクトリには、Codex `[Control Tower]` が作る固定レビュー対象を置く。
パックは通常の進捗報告ではなく、外部判断が必要な節目だけに作成する。

## 位置と命名

- 位置: `docs/review-packs/<PACK_ID>.md`
- `<PACK_ID>` は一意で、対象コミットを固定後に決める。
- パックは作成後に書き換えない。内容が変わる場合は新しい `PACK_ID` を作る。

## 対象にする節目

- 新しい権限又は実行境界
- 制御経路の設計・実装前レビュー
- Stage 又は Day の開始境界
- 完了受入れ
- セキュリティ、破壊的操作、認証、費用、製品方針の境界

通常の進捗、局所的な実装判断、既に許可された範囲内の小さな修正は Control Tower で扱い、
パックを作らない。

## 手動パイロットの境界

ユーザーが `prompts/EXTERNAL_GATE_REVIEW_PROMPT.md` とパックを外部 ChatGPT へ貼り付け、
返答全文を Control Tower に戻す。Control Tower は `PACK_ID` と `REVIEWED_COMMIT` が一致する
返答だけを判断材料にする。手動貼り付けは、既存 Review Bridge/Watcher の未完了記録を変更せず、
それらの返信を置き換えない。

このテンプレートの導入自体は、既存の自動レビュー運用の停止やポリシー改訂を意味しない。
実運用の切替は、別の固定パックで明示的に判断する。
