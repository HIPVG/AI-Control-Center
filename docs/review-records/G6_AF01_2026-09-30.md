## Production composition

- `LocalLLMDayProgram.prepare_intent()` now creates the single immutable RunIntent
  before any trusted fact is resolved. Compatibility `prepare_go()` delegates to
  that method and evaluates admission against the same intent.
- `RunCoordinator` passes that exact RunIntent to its resolver, evaluates admission
  against it, persists it, and hands its run ID to the executor. The response carries
  the run-bound preflight fact for audit.
- `ControlCenterEngine` composes the accepted Grant, Observation and Fact stores and
  `AuthorityFactResolver`. Production defaults use versioned config grants, dedicated
  state stores, current AI-Control-Center commit, the LocalLLM checkout and Day 6's
  declared prerequisite paths. Existing injected test boundaries remain supported.
- `RunProductComposition` and `/api/local-llm/runs` read the create-only preflight
  fact by current run ID. `RunReadModel` rejects mismatched fact identity and exposes
  it read-only without reinterpreting permission or completion.
- Legacy start still calls the same coordinator guard.

The historical authority companion remains bound to its original product target.
Because production resolves the current product commit, that old record cannot
admit a later build without a separately matching grant.
