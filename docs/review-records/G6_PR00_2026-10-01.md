## Change

Added one product composition operation that takes the current immutable RunIntent
and already validator-accepted Day Evidence, revalidates each value through the
existing `CompletionEvidenceEvaluator`, and creates deterministic records bound to
the exact run and criterion. The operation computes all criterion results before
mutating the Day snapshot, so one invalid source rejects the binding without partial
application. Historical nullable Evidence remains unchanged.

The Day contract reevaluation now prefers strict records matching both the current
run and criterion. When no exact strict record exists it may still use only fully
nullable legacy records for Day compatibility; a record bound to another run or
criterion is never selected as a substitute.
