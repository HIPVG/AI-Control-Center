## Implemented behavior

- Added a production `RunCoordinator` that resolves trusted facts server-side,
  persists one immutable `RunIntent`/initial `RunControl` before a Day effect, and
  passes the same run ID to an injected executor only after admissible preflight.
- A blocked admission persists the reason and resume target and invokes no executor.
- A current nonterminal run rejects duplicate Go before creating another identity or
  effect.
- The legacy `/api/local-llm/day/{day}/start` route now enters the same coordinator;
  the old controller start remains an internal executor boundary.
- `JsonRunStore` now enumerates current runs and supports guarded versioned updates.
  The immutable intent, expected prior timestamp and append-only state history must
  match; the prior current record is retained before atomic replacement.
- Production preflight facts default to unknown, so this wiring does not itself
  authorize or start a Day. Tests use an injected deterministic executor only.
