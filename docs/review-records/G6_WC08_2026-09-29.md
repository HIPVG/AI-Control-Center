Implemented immutable run-bound telemetry models and a create-only JSON persistence
boundary. Each metric keeps a value or explicit unknown reason, unit, authoritative
source when known, and timezone-aware observation time. Manual relay count, reasoned
interventions, attempt count and attempt limit, input/output tokens and cost remain
separate fields under one run ID.

Validation rejects reasonless intervention, intervention from another run, duplicate
intervention identity, relay-count inconsistency, known values without a source, and
unknown values without a reason. Unknown token values round-trip as null rather than
zero. Attempt actual and authorized limit retain distinct sources; an over-limit actual
is preserved as evidence rather than silently corrected. The JSON store uses create-only
file semantics, so an existing run telemetry snapshot cannot be overwritten.
