## Implementation

`LocalLLMDayProgram` now owns a narrow settlement notifier boundary. Start, Resume
and authorized infrastructure-recovery workers all capture the current run ID and use
one wrapper around the existing `_execute` state machine. After `_execute` returns,
the wrapper:

1. ignores callback-free and unbound legacy runs;
2. requires the captured run ID to match the current snapshot;
3. requires a non-active Day state;
4. performs one final synchronous snapshot save;
5. invokes the bound notifier once for that worker execution episode;
6. records accepted, rejected and exception outcomes without retrying them.

Production Engine binds the notifier to the existing
`RunProductComposition.execution.project_day_state` method. No state mapping or
completion rule was duplicated. Initial asynchronous Go still returns the preflight
RunRecord; later GET readback observes the settled projected state.
