Implemented a fixture-only HumanDecision control that keeps Reviewer-recommendation
endorsement, Codex-artifact acceptance, gate exit and implementation authority as
separate subject types. A response is classified only when its decision ID, revision,
subject type, target commit, requested effect and subject-binding basis match a fixed
request and its source is a directly recorded conversation. The exact human text,
decider, channel, message ID, source class, receive time and all bindings are retained.

A classified response still has no effect. It creates at most one confirmation report
per message/decision/revision and waits for an exact response binding the confirmation,
original report/response, decision/revision, commit, subject and effect. Positive result,
successful continuation and effect evidence are all required. The returned projection
allows only the named effect: artifact acceptance is not gate exit; gate exit does not
authorize the next stage, PR close or merge; no path mutates Day state.

reviewer-proposal effect limits, artifact-only acceptance, duplicate suppression with
coexisting requests, mismatch failure, proxy/delivery failure provenance, and gate-exit-
