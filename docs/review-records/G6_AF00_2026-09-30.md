## Implemented boundary

- Added strict immutable `AuthorityGrant`, `PrerequisiteObservation` and
  `PreflightFactRecord` contracts.
- Added interface-backed create-only JSON stores. File names are hashes of record
  identity, records are revalidated on write/read, corrupt records fail closed, and
  the same run ID cannot overwrite an existing preflight fact.
- Added `AuthorityFactResolver`, which accepts one immutable `RunIntent`. Permission
  resolves only for one unique non-revoked, non-expired grant matching the Day,
  allowed effect, product target commit, contract/policy/config/Git fingerprints,
  exact limits, current LocalLLM commit and authority-record hash.
- External prerequisites are resolved independently. The Day-specific observation
  must match Day, LocalLLM commit, Git fingerprint and the exact declared path set;
  every path is checked under the configured project root.
- Both results and their provenance or unknown reason are persisted as one
  create-only preflight record bound to the RunIntent run ID.
- Added a strict machine-readable companion for the existing G7 clean-baseline
  decision. It is bound to the historical product target commit and cannot silently
  authorize a later build.

AF-00 does not wire this resolver into `RunCoordinator` or the production Engine.
That same-intent composition change remains AF-01 and is blocked pending acceptance
of this fixed card.
