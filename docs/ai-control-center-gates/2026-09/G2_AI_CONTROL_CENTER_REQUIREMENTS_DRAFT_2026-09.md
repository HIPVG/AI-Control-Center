## 1. 目的、対象、用語

**対象製品**は AI-Control-Center である。利用者 **広瀬剛** が LocalLLM-Lab の構成済み Day を一つ選び、Go を押すと、製品は許可済み範囲で当該 Day の計画、証拠収集・検証、通常作業、必要な限定修正、レビュー応答、停止を接続する。目的は、AI 間の定常的なプロンプト・結果の手動中継と細かな端末操作を減らし、選択 Day の結果を証拠付きで提示することにある。

| 用語 | この文書での意味 |
| --- | --- |
| 製品工程 G0〜G9 | AI-Control-Center を作る工程。Day 1〜14 とは別。 |
| Day | LocalLLM-Lab の一つの業務・研究契約。選択した Day 以外を自動開始しない。 |
| 実証範囲 | 最初に実環境で成立を示す、一つの Day と必要な最小経路。 |
| 最終提供範囲 | Day 1〜14 を扱う製品として提供するための、後続の受入範囲。 |
| current runtime state | 現在のプロセス、通信、保存状態、実行 ID により確認できる状態。過去の保存値とは分ける。 |
| historical state | 過去実行の保存・履歴。current runtime の証拠に転用しない。 |

## 2. 成功指標、非目的、優先順位

| 区分 | 定義 |
| --- | --- |
| 成功指標 S01 | 選択 Day の UI 操作から、同一実行 ID の結果・条件別証拠・停止理由まで追跡できる。 |
| 成功指標 S02 | 通常経路で利用者が AI 間の指示・結果を手動転記する回数を 0 回として測定・記録できる。例外介入は理由とともに記録する。 |
| 成功指標 S03 | 不足・無効証拠、範囲外、上限到達、重複／不一致レビューでは完了表示をせず、決められた停止又は判断依頼へ遷移する。 |
| 非目的 N01 | G2で製品コード、テスト、Day実行、起動、外部送達を行うこと。 |
| 非目的 N02 | 未承認の全 Day 実行、汎用エージェント基盤、新規インフラ、既存資産の削除・再作成。 |
| 非目的 N03 | 過去状態、AI自己報告、テスト終了だけを製品／Dayの受入にすること。 |

優先順位は **Must**: A01〜A06 と安全境界、**Should**: 可観測性・保守容易性、**May**: G1で `UNMAPPED` であった表示の拡張方式である。Must と衝突する利便性・一般化は後回しにする。

## 5. 実証と最終提供の分離

| 項目 | 実証範囲 | Day 1〜14 最終提供範囲 |
| --- | --- | --- |
| 対象 | **2ケース**: C-01 Day 1 の既終了参照事例、C-06 Day 6 の参照事例なしの新規実証候補。Day 1 は再実行しない。Day 6 の実行は G3 の別承認まで開始しない。 | 全 Day を一括実行しない。各 Day の個別契約と受入を尊重する。 |
| 目的 | 参照がある既終了ケースと、参照なしの新規ケースを比較し、参照再利用と新規証拠生成を混同しない。今回の比較は画面操作を伴わず、チャットへ結果を返す。 | すべての対象 Day で、必要な安全、実施、許可内の自動修復、解決不能時の人間への判断要請（エスカレーション）、証拠、停止、復旧を提供する。 |
| 証拠 | C-01 は来歴・条件互換性を検証した reference record。C-06 は同一 run ID の計画・操作・結果・Evidence。UI表示の受入は本比較の対象外。 | Day別の互換性、回帰、運用記録、実UI受入を追加する。 |
| 選定基準 | 非破壊、固定条件、必要な証拠を出せること、費用・外部効果が承認範囲内であること。 | G3以降の実証結果とG4/G5の計画で決める。 |

### 5.1 比較ケースと固定条件

| ケース | 位置付け | 固定条件 | 受入上の制約 |
| --- | --- | --- | --- |
| C-01 | **Day 1 の既終了参照事例**。広瀬剛の申告に基づく `REPORTED` な参照であり、今回の再実行ではない。 | 当該実行の source revision、Day 1契約／runbook版、Evidence ID・validator結果、実行時刻、保存先を reference record で対応付ける。いずれかが欠ける場合、比較基準には採用せず `NOT_EVALUABLE` とする。 | 過去の完了表示、履歴、状態ファイルだけを受入証拠にしない。 |
| C-06 | **Day 6 の参照事例なし新規実証候補**。`config/local-llm-day-actions.json` の trusted catalog は `TRUSTED_NOT_EXECUTED` と読む。隔離された過去状態にある Day 6 完了表示は reference に採用しない。 | G3開始時の `C:\LocalLLM-Lab` revision、Day 6契約／runbook hash、許可対象パス、実行 ID、ACTIVE_WORK 30分、最大2試行、有償操作0円、token値は取得できる実測のみ、を記録する。 | 新規実行の前に、実行・外部通信・認証の権限を再確認する。参照の代用、条件緩和、無変更再試行をしない。 |

Day 6 は planned / actual / forecast / snapshot time を schema 分離し、欠落した time fact を fail closed とする Day である。C-01 と別の目的・Evidence type を持つため、成果の優劣比較ではなく、**参照再利用あり／なしにおける製品の制御・証拠・停止の比較**に限る。
